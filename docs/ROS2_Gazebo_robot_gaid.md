# ROS 2 & Gazebo 4足歩行ロボット開発ガイド

4足歩行ロボット（クアドラペッド）のシミュレーションは、2輪駆動ロボットに比べて構造や制御が複雑です。開発を始めるための全体像を解説します。

## 1. 4足歩行ロボットの基本構造（関節構成）
一般的な4足歩行ロボットは、1本の脚に3つの自由度（関節）を持ち、計12個のモーターで動きます。

*   **Hip Roll (股関節・外転内転)**: 脚を左右に開閉する関節
*   **Hip Pitch (股関節・屈曲伸展)**: 脚を前後に振る関節
*   **Knee Pitch (膝関節)**: 膝を曲げ伸ばしする関節

これらを「前左 (FL)」「前右 (FR)」「後左 (RL)」「後右 (RR)」の4箇所に配置します。

## 2. 制御の仕組み（アーキテクチャ）
2輪ロボットのように「速度（cmd_vel）」を送るだけでは歩けません。以下の3層構造が必要になります。

1.  **音声/速度指令 (`/cmd_vel`)**: 「前進せよ」「旋回せよ」という大まかな指示。
2.  **歩行ジェネレーター (Gait Generator)**: 指令を受け、4本の脚をどういうタイミング（トロット、バウンドなど）でどこに着地させるかを計算（逆運動学: IK）し、12個の関節の目標角度を出力するプログラム。
3.  **ros2_control (コントローラー)**: 計算された目標角度に合わせて、Gazebo上の各関節のバーチャルモーターを正確に動かす。

## 3. おすすめのオープンソースプロジェクト
ゼロから作ると数ヶ月かかるため、以下の実績あるパッケージをベースに学習・開発することを強く推奨します。

### ① CHAMP (Quadruped Control Framework)
ROS 2に対応した最も有名な4足歩行制御フレームワークです。
*   **特徴**: 自作のロボットモデルでも、関節の位置を登録するだけで自動的に歩行アルゴリズムを生成してくれます。
*   **GitHub**: `https://github.com`

### ② Unitree ROS 2 Simulation
市販の4足歩行ロボット「Unitree Go1 / Go2」のシミュレータ環境です。
*   **特徴**: 実機に近い高精度な物理挙動をGazebo上で再現できます。

## 4. 次のステップ
まずは、世界中の開発者が利用している `CHAMP` をご自身のROS 2環境にインストールし、サンプルロボットがGazebo上で歩く姿を確認することから始めてみてください。
